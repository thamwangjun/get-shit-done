### Phase 18: Fork Tag Corpus Tests
**Goal**: Two new regression test files enforce the fork's `<persona>` and `<intent>` XML tag standards across the full corpus, with no new regressions in pre-existing tests — 32 `<objective>`-file failures in the intent test are expected and excluded from the completion gate (conversion deferred to a follow-on phase)
**Depends on**: Phase 17 (working tree clean, test suite at 4163 pass / 2 fail baseline)
**Requirements**: PERSONA-01, INTENT-01, TEST-GATE-01
**Success Criteria** (what must be TRUE):
  1. `npm test` output includes `fork-persona-tag.test.cjs` with 62 subtests (31 agents × 2 checks) passing and 0 failures — each agent is individually verified for `<persona>` presence and `<role>` absence
  2. `npm test` output includes `fork-intent-tag.test.cjs` with one subtest per command file (79 total); 47 pass (<intent> files), 32 fail by design (<objective> files — expected and documented); 0 failures on <task>-free files
  3. The full test suite total passing count exceeds the pre-phase baseline of 4163, with 0 NEW failures in pre-existing tests (2 pre-existing qwen-install.test.cjs failures are acceptable)
  4. Introducing a deliberate `<role>` tag into any agent file (then reverting) causes `fork-persona-tag.test.cjs` to fail, confirming the guard is active and not a vacuous pass
**Plans**: 2 plans

Plans:
