<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test subprocess → filesystem | Tests rename/restore hooks/dist/ on the real repo filesystem; a crashed test could leave the backup directory in place, corrupting subsequent test runs |
| test subprocess → system | spawnSync runs the real install.js in a subprocess with CLAUDE_CONFIG_DIR redirected; a bug in install.js could write files outside the temp dir if the env override is ignored |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | hooks/dist/ rename in beforeEach/afterEach | mitigate | Test file already uses try/catch in restoreHooksDist() and removes stale backups in hideHooksDist() before renaming — isolation is already hardened; executor must not modify the test's cleanup logic |
| T-05-02 | Denial of Service | Parallel test runs (--test-concurrency=4) | accept | Tests use distinct tmpDir per run via mkdtempSync; hooks/dist/ rename is shared state but tests are in the same describe group and Node's test runner serializes within a describe block — low risk given test file structure |
| T-05-03 | Elevation of Privilege | spawnSync install.js writes to CLAUDE_CONFIG_DIR | mitigate | Tests set CLAUDE_CONFIG_DIR to a mkdtemp location and cleanupDir() removes it in afterEach — no writes escape to real $HOME/.claude/ |
| T-05-04 | Information Disclosure | Test stdout/stderr captured in runInstaller() | accept | Output is used only for assertion messages; no secrets in the install flow; low-value target |
| T-05-05 | Repudiation | Doc updates to REQUIREMENTS.md / ROADMAP.md | accept | Changes committed to git — full audit trail exists |
</threat_model>
