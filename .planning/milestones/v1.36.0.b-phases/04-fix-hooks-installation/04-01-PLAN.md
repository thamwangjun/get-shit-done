<objective>
Fix `bin/install.js` so that users cloning the repo and immediately running `node bin/install.js --claude --global` get GSD hooks installed, even when `hooks/dist/` has not been built.

Purpose: `hooks/dist/` is gitignored and only produced by `prepublishOnly`, so it is always absent on a fresh clone. The current code silently skips hooks copy when the directory is missing. This fix adds an on-demand build trigger with a clear console notice.

Output: A modified `bin/install.js` containing the `ensureHooksDist(src)` helper and updated success message logic.
</objective>

**Step 1: Add the helper function.**

Find the block of named helper functions starting at line 155 (`getDirName`). Insert `ensureHooksDist` after the last helper in that region and before the large CODEX_AGENT_SANDBOX constant block. Include a JSDoc comment matching the existing helper style.

The exact function body to add:

```javascript
/**
 * Ensure hooks/dist/ exists. If absent, builds it on-demand using scripts/build-hooks.js.
 * Aborts the installer with a non-zero exit if the build fails.
 * @param {string} src - GSD package root directory
 * @returns {boolean} true if an on-demand build was triggered, false if dist/ was already present
 */
function ensureHooksDist(src) {
  const hooksDist = path.join(src, 'hooks', 'dist');
  if (fs.existsSync(hooksDist)) return false;

  console.log(`  ${cyan}▶${reset} Building hooks from source...`);
  const buildScript = path.join(src, 'scripts', 'build-hooks.js');
  const { spawnSync } = require('child_process');
  const result = spawnSync(process.execPath, [buildScript], {
    encoding: 'utf8',
    stdio: ['pipe', 'pipe', 'pipe'],
  });
  if (result.status !== 0) {
    console.error(`\n  ${yellow}Build failed!${reset} Could not build hooks/dist/:`);
    if (result.stderr) console.error(result.stderr);
    process.exit(1);
  }
  return true;
}
```

Key constraints to verify during implementation:
- `const { spawnSync } = require('child_process');` is INSIDE the function body (not at module scope) — per CRITICAL pitfall documented in RESEARCH.md Pitfall 1
- `stdio: ['pipe', 'pipe', 'pipe']` suppresses stdout from build-hooks.js (per D-05) while capturing stderr for error reporting
- `return false` on early exit (dist/ already present), `return true` when a build was triggered — this return value is used in Task 2 for the success message
