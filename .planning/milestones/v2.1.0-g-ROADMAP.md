## Milestone Summary

**Key Decisions:**

- Detection scope: inline `#NNN`, parenthetical `(#NNN)`, and feat-form `feat-NNNN` citations — word-form "issue NNNN" not present in corpus
- Allowlist two-tier design: `PLACEHOLDER_DIGITS` (global Set — `1`, `2`, `123`) + `FILE_ALLOWLIST` (per-file map for context-dependent exemptions like `config.md:47 #2439`)
- Guard test inline detection (no external scanner dependency) ensures the guard remains self-contained after scanner deletion in Phase 65-02
- `templates/` dir: 0 citations found, no cleanup needed (sole hit `#123` was `PLACEHOLDER_DIGITS` — benign)
