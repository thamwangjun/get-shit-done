# Phase 55.2 Plan 02: Register verify.codebase-drift + intel.* family handlers (D-204)

Two hard "no native handler registered" failures cleared by registering `verify.codebase-drift` (native TypeScript port of CJS logic) and the entire `intel.*` family (8 handlers, import-only — bodies already correct); golden-policy coverage gate stays green; D-204 register-by-default choice recorded in VERIFICATION.

## What Was Built

**Task 1: verify.codebase-drift native handler**

- `sdk/src/query/verify.ts`: Added `verifyCodebaseDrift` — a full native TypeScript port of
  `cmdVerifyCodebaseDrift` from `verify.cjs:1331-1459` plus the drift detection library logic from
  `drift.cjs` (`detectDrift`, `readMappedCommit`, `chooseAffectedPaths`, `classifyFile`,
  `isPathMapped`, `buildMessage`). Uses `execGit` for git diff; `loadConfig` for threshold/action.
  No subprocess call — avoids the infinite recursion a prior Phase 6 stub caused.
- `sdk/src/handlers/verify/index.ts`: Added `verifyCodebaseDrift` import and
  `'verify.codebase-drift': verifyCodebaseDrift` entry to `VERIFY_FAMILY_HANDLERS`.
- `sdk/src/query/command-manifest.verify.ts`: Added `verify.codebase-drift` manifest row mirroring
  `verify.schema-drift`.

**Task 2: intel.* family registration**

- `sdk/src/query/command-static-catalog-domain.ts`: Imported all 8 intel handlers
  (`intelStatus`, `intelDiff`, `intelSnapshot`, `intelValidate`, `intelQuery`,
  `intelExtractExports`, `intelPatchMeta`, `intelUpdate`) and added 16 static catalog entries
  (dotted + spaced canonical for each). Reversed the Phase 6 ADR-3524 omission comment.
- `sdk/src/query/command-manifest.non-family.ts`: Added 8 manifest rows for intel.* commands.
- `sdk/src/golden/golden-integration-covered.ts`: No change needed — `intel.update` was already
  at line 21; registering it makes the entry valid instead of stale.
- `55.2-VERIFICATION.md`: Updated rows #1-#7, #17 with confirmed causes and Plan 02 status;
  added Plan 02 Outcome section recording D-204 choice, both handler decisions, and classification update.

## Key Decisions Made

**D-204 Path A (register-by-default) confirmed for both handlers:**
- `verify.codebase-drift`: Full native port avoids the recursion issue; CJS oracle matches at runtime.
- `intel.*`: Handler bodies in `intel.ts` already byte-matched the CJS oracle; registration only.

**verifyCodebaseDrift is inline, not a subprocess stub:**
- The prior Phase 6 stub (execFileSync back to gsd-tools) created SDK→CLI→SDK infinite loop.
- Native port in TypeScript has no subprocess dependency.
