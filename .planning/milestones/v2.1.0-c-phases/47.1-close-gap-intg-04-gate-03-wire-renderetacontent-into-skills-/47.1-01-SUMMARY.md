## What Was Built

### Task 1: Fix — Wire renderEtaContent into wrappedConverter

In `get-shit-done/bin/lib/runtime-artifact-layout.cjs`, the `skillsKind()` function's `stage()` method now:
1. Captures `srcCommandsDir = findInstallSourceRoot(configDir)` as a named variable (was previously inline)
2. Derives `etaViewsRoot = path.join(srcCommandsDir, '..', '..')` — two levels up from `commands/gsd` yields the repo root, matching `_etaSourceRoot` used in `bin/install.js`
3. Calls `installExports.renderEtaContent(content, skillName, etaViewsRoot)` before passing the rendered content to `realConverter`

This closes BLOCKER-01: all 13+ command files with `<%~ include()` directives are now rendered at install time for all 11 skills-based runtimes (claude-global, cursor, codex, copilot, antigravity, windsurf, augment, trae, qwen, hermes, codebuddy).

### Task 2: Test — Expand TEST-01 with <%~ detection

Added a second `test()` inside the existing `TEST-01` describe block in `tests/install-eta-regression.test.cjs`. The new test:
- Runs a full Claude install via `installRuntimeArtifacts('claude', tmpDir, 'global', RESOLVED_CORE)`
- Walks all installed `.md` files recursively
- Fails unconditionally if any file contains a `<%~` substring (per D-03: no allowlist needed)
- Provides failure messages with file path, line number, and offending line content
