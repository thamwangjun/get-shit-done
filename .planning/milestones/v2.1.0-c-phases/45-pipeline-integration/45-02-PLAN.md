## Goal

Write a Node.js conversion script and run it across all 82 source files to replace install-time static reference patterns with Eta include tags, and runtime `.planning/` bare-line refs with the cross-runtime bash form.

## Context

- **D-06**: Install-time GSD static refs → Eta include tag (4 input forms → 1 output form)
- **D-07**: Runtime `.planning/X` bare-line refs → `` !`cat .planning/X` ``
- **D-08**: Inline `@~` within prose → retain as-is (instructional text directed at AI, not injected content)
- **D-10**: Conversion scope: 55 command files, 7 agent files, 19 workflow files, 1 reference file (~180 lines total)

Deferred: Converting inline `@~` prose references (e.g., `"See @~/.claude/.../foo.md"`) — these are intentionally out of scope.

## Tasks

### Task 1: Write scripts/convert-refs.cjs

**Files:** `scripts/convert-refs.cjs`

**Steps:**

Write a Node.js CommonJS script that applies D-06 and D-07 transformations atomically across the four target directories.

The script must implement these transformations, applied **only to bare lines** (a line whose trimmed content is entirely the reference pattern):

**D-06 transformations (install-time static → Eta include):**

| Input form | Output form |
|---|---|
| `` !`cat $HOME/.claude/get-shit-done/X` `` | `{%~ include('get-shit-done/X') %}` |
| `` !`cat ~/.claude/get-shit-done/X` `` | `{%~ include('get-shit-done/X') %}` |
| `@~/.claude/get-shit-done/X` | `{%~ include('get-shit-done/X') %}` |
| `@$HOME/.claude/get-shit-done/X` | `{%~ include('get-shit-done/X') %}` |

**D-07 transformation (runtime .planning/ → bash cat form):**

| Input form | Output form |
|---|---|
| `@.planning/X` (bare line only) | `` !`cat .planning/X` `` |
| `` !`cat .planning/X` `` | retain unchanged |

**D-08 constraint (do not convert inline prose):**

A line is a "bare line" only if the trimmed line content is ENTIRELY the reference pattern — nothing before or after it on the line. Lines where `@~` appears mid-sentence (e.g., `"Reference @~/.claude/get-shit-done/..."`) must not be transformed.

**Script structure:**

function transformLine(line) {
  const trimmed = line.trim();
  // D-06: !`cat $HOME/.claude/get-shit-done/X` (bare line)
  const catHomeMatch = /^!`cat \$HOME\/\.claude\/get-shit-done\/(.+)`$/.exec(trimmed);
  if (catHomeMatch && trimmed === line.trim() && line.trim() === trimmed) {
    return `{%~ include('get-shit-done/${catHomeMatch[1]}') %}`;
  }
  // D-06: !`cat ~/.claude/get-shit-done/X` (bare line)
  const catTildeMatch = /^!`cat ~\/\.claude\/get-shit-done\/(.+)`$/.exec(trimmed);
  if (catTildeMatch) {
    return `{%~ include('get-shit-done/${catTildeMatch[1]}') %}`;
  }
  // D-06: @~/.claude/get-shit-done/X (bare line)
  const atTildeMatch = /^@~\/\.claude\/get-shit-done\/(.+)$/.exec(trimmed);
  if (atTildeMatch) {
    return `{%~ include('get-shit-done/${atTildeMatch[1]}') %}`;
  }
  // D-06: @$HOME/.claude/get-shit-done/X (bare line)
  const atHomeMatch = /^@\$HOME\/\.claude\/get-shit-done\/(.+)$/.exec(trimmed);
  if (atHomeMatch) {
    return `{%~ include('get-shit-done/${atHomeMatch[1]}') %}`;
  }
  // D-07: @.planning/X (bare line) → !`cat .planning/X`
  const atPlanningMatch = /^@\.planning\/(.+)$/.exec(trimmed);
  if (atPlanningMatch) {
    return `!\\`cat .planning/${atPlanningMatch[1]}\\``;
  }
  // D-07: !`cat .planning/X` → retain (no change)
  return null; // null = no change
}
