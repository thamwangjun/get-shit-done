    Create `scripts/scan-citations.cjs` as a zero-dependency CommonJS scanner (per D-08).

    Module structure mirrors `scripts/normalize-step-numbers.cjs`:
    - Shebang `#!/usr/bin/env node` + module JSDoc citing Phase 64 / CITE-01 and decisions D-08/D-09/D-10
    - `'use strict';` + `const fs = require('fs'); const path = require('path');` only — no other dependencies
    - `PROJECT_ROOT = path.join(__dirname, '..')`
    - `SCAN_DIRS` constant covering exactly these 5 directories (per CONTEXT.md domain):
      `commands`, `get-shit-done/workflows`, `agents`, `get-shit-done/references`, `get-shit-done/templates`
      (Note: 5 dirs, not the 3 used in `normalize-step-numbers.cjs`. No PATTERN_C_EXCLUDES filter applies here.)
    - `collectMarkdownFiles(dir)` helper copied verbatim from the analog (ENOENT-tolerant, recursive, .md only)
    - Module-scope file collection loop populating `ALL_FILES` from `SCAN_DIRS`

    Citation detector regexes (per D-04, D-05, D-10) — applied in a single pass per line:
    - `inline`: `/(?<![0-9a-fA-F#])#(\d+)\b/` matches `#NNN` where N is one or more digits. The lookbehind prevents matching hex color tails (e.g. `#e8c170` last 4 hex chars) and `##` heading markers from triggering. Apply globally with `/g` flag.
    - `parenthetical`: classify any `inline` hit whose immediately preceding character on the line is `(` and followed by `)` as category `parenthetical` instead of `inline`. Implementation: after matching `#NNN`, inspect surrounding characters; emit `parenthetical` when wrapped in `(...)`, otherwise `inline`.
    - `word-form`: `/\b(?:issue|PR|pull request)\s+(\d{2,})\b/gi` — matches "issue NNN", "PR NNN", "pull request NNN" with 2+ digits to avoid false positives on small numbers.
    - `feat-form`: `/\bfeat-(\d{3,})\b/g` — matches `feat-NNNN` with 3+ digit tracker IDs (per D-05; `feat-3347` is the confirmed canonical hit).

    Per-line scan loop semantics (per D-10):
    - Initialize `inCodeBlock = false`, `inFrontmatter = false`, `frontmatterDone = false` at the start of each file
    - Code-fence toggle: lines matching `/^```/` flip `inCodeBlock`; `continue` on the toggle line and while `inCodeBlock` is true (symmetric skip, copy from analog)
    - Frontmatter toggle: before `frontmatterDone`, a line whose trim equals `---` flips `inFrontmatter`; when `inFrontmatter` flips from true to false, set `frontmatterDone = true`. Skip both the toggle lines and any line while `inFrontmatter` is true. After `frontmatterDone = true`, never enter frontmatter mode again for that file.
    - For every non-skipped line, run all four detector regexes; for each match, push `{ file: relPath, line: lineNumber, text: matchedSubstring, category: 'inline' | 'parenthetical' | 'word-form' | 'feat-form' }` onto a `hits` array. `relPath` is forward-slash-normalized (`.split(path.sep).join('/')`).

    File-read error handling: wrap `fs.readFileSync` in try/catch; on error, `continue` to the next file silently (per the analog pattern lines 277–280).

    Output (per D-09): after all files scanned, `process.stdout.write(JSON.stringify(hits, null, 2) + '\n')` then `process.exit(0)`. Do not use `console.log`.

    Argument handling: accept zero arguments. If any argument is passed, print `Unknown flag: <arg>\nUsage: node scripts/scan-citations.cjs\n` to stderr and exit 1 (mirror the analog argument validation block).

    The script must NOT modify any files — read-only scan.
