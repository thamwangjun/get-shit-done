# Requirements: v1.37.2 Positive Framing TDD Pass

## Milestone Goal

Re-apply and expand the positive framing quality bar across all prompt content files using TDD — write failing tests first, fix all violations and warnings, tests green.

## Active Requirements

### Scanner Expansion (SCAN)

- [x] **SCAN-01**: Scanner detects all bare `avoid [verb]` directives without a positive complement — hard failure if detection is reliable, warn-only if false-positive risk is high
- [x] **SCAN-02**: Scanner detects bare `don't [verb]` directives with `isFactualDont()` helper — hard failure if detection is reliable, warn-only if false-positive risk is high
- [x] **SCAN-03**: Scanner detects `<anti_patterns>` tag usage (both opening and closing tags, deduped to 1 violation per block) — hard failure if detection is reliable, warn-only if false-positive risk is high
- [x] **SCAN-05**: Scanner detects bare `must not` / `MUST NOT` directives — hard failure if manual review finds reliable detection, warn-only otherwise
- [x] **SCAN-06**: Scanner detects bare `should not` / `should NOT` directives — hard failure if manual review finds reliable detection, warn-only otherwise
- [x] **SCAN-07**: Scanner detects `cannot` directives — warn-only expected (high false-positive rate in corpus); manual review classifies each match as TP/FP before writing assert
- [x] **SCAN-08**: Scanner detects `won't` directives — warn-only expected (corpus shows mostly factual uses); manual review classifies each match
- [x] **SCAN-09**: Scanner detects `will not` directives — warn-only expected (corpus shows mostly informational uses); manual review classifies each match
- [x] **SCAN-04**: New scanner subtests that achieve reliable detection are verified in a failing state against unmodified upstream files before any file edits (TDD red gate applies to hard-failure tests only); manual review of every corpus match documented inline in PLAN.md before writing each assert
