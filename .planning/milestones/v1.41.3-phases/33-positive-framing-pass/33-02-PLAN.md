**cmdStateJson function (lines 1102–1131 in state.cjs):**
```javascript
function cmdStateJson(cwd, raw) {
  const statePath = planningPaths(cwd).state;
  if (!fs.existsSync(statePath)) {
    output({ error: 'STATE.md not found' }, raw, 'STATE.md not found');
    return;
  }

  const content = fs.readFileSync(statePath, 'utf-8');
  const existingFm = extractFrontmatter(content);
  const body = stripFrontmatter(content);

  // Always rebuild from body + disk so progress counters reflect current state.
  // Returning cached frontmatter directly causes stale percent/completed_plans
  // when SUMMARY files were added after the last STATE.md write (#1589).
  const built = buildStateFrontmatter(body, cwd);

  // Preserve frontmatter-only fields that cannot be recovered from the body.
  if (existingFm && existingFm.stopped_at && !built.stopped_at) {
    built.stopped_at = existingFm.stopped_at;
  }
  if (existingFm && existingFm.paused_at && !built.paused_at) {
    built.paused_at = existingFm.paused_at;
  }
  // Preserve existing status when body-derived status is 'unknown' (same logic as syncStateFrontmatter).
  if (built.status === 'unknown' && existingFm && existingFm.status && existingFm.status !== 'unknown') {
    built.status = existingFm.status;
  }

  output(built, raw, JSON.stringify(built, null, 2));
}
```

**The conflict between #3242 Bug A and #1589:**
- #1589 requires `state json` to return FRESH disk-derived progress when frontmatter has STALE values (total_phases matches disk count).
- #3242 Bug A requires `state json` to return CURATED frontmatter progress when it represents cross-milestone aggregates (total_phases exceeds disk count).

**Discriminating heuristic:**
- `existingFm.progress.total_phases > built.progress.total_phases` → curated cross-milestone block → preserve existingFm.progress
- `existingFm.progress.total_phases <= built.progress.total_phases` → stale frontmatter → use disk-derived built.progress (existing behavior)

**Why this works for each test scenario:**
- Bug A: frontmatter total_phases=12, disk dirs=6 → buildStateFrontmatter produces total_phases≤6 → 12 > 6 → preserve curated. ✓
- #1589 test 3: frontmatter total_phases=4, disk has 4 complete phases → buildStateFrontmatter produces total_phases=4 → 4 > 4 is false → use disk-derived. ✓
- #1589 tests 1&2: no frontmatter progress block → existingFm.progress is null → condition not met → use disk-derived. ✓
