## Phase Details

### Phase 4: Fix Hooks Installation
**Goal**: Users can run `node bin/install.js --claude --global` from a cloned repo and get GSD hooks installed, whether or not hooks/dist/ has been built
**Depends on**: Nothing (first phase of this milestone)
**Requirements**: FIX-01, FIX-02
**Plans**: 1 plan
**Success Criteria** (what must be TRUE):
  1. A user who clones the repo and runs the install command immediately finds GSD hooks present in `$HOME/.claude/hooks/` — no manual build step required
  2. When install.js triggers the on-demand hooks build, the user sees a console notice identifying what happened (not a silent operation)
  3. A user who has already built hooks/dist/ sees the same install outcome as before (existing path is unaffected)

Plans:
- [x] 04-01-PLAN.md — Add ensureHooksDist helper and update install.js success message

### Phase 5: Regression Coverage
**Goal**: An automated test in the existing test suite confirms hooks are installed correctly when hooks/dist/ is absent at install time, preventing the silent-skip bug from reappearing
**Depends on**: Phase 4
**Requirements**: FIX-03
**Plans**: 1 plan
**Success Criteria** (what must be TRUE):
  1. `npm test` passes with a test that explicitly exercises the dev-install path (hooks/dist/ absent at install time)
  2. If the Phase 4 fix were reverted, the regression test would fail — the test is not vacuously passing

Plans:
- [x] 05-01-PLAN.md — Verify regression test suite passes and reconcile milestone state
