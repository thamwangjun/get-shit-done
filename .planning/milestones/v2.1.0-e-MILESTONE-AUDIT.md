Two blockers identified in the prior audit run are now closed:

1. **EXPOSE-03 SDK codex catalog-effort drop** (b4bc8cc0): `config-query.ts:314` introduces `rawSlotForRuntime` — the pre-strip slot (`phaseTier` string or `rawAlias`) — so `parseModelEffort(rawSlotForRuntime).effort` at line 331 correctly reads catalog-assigned slot effort before the `runtimeTier.reasoning_effort` fallback. Previously `parseModelEffort(tier).effort` was called on the already-stripped alias, returning null and allowing Codex per-tier built-in to override catalog intent.
