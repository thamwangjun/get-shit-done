<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream/main remote → local thamw-main | Upstream commits are trusted source; however, auto-merge of fork-patched files must never be accepted without grep verification |
| git merge auto-resolution → conflict-marked files | Git's three-way merge algorithm may silently choose upstream's version for the 3 high-risk files without marking them as conflicted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | hooks/gsd-check-update-worker.js | mitigate | grep thamwangjun after merge; reject upstream's npm semver isNewer function |
| T-07-02 | Tampering | bin/install.js | mitigate | grep ensureHooksDist after merge; never use `git checkout --theirs` on this file |
| T-07-03 | Tampering | tests/agent-frontmatter.test.cjs | mitigate | grep "only use" after merge; ensure prohibition-form upstream assertion is not taken |
| T-07-04 | Denial of Service | bin/install.js ensureHooksDist | mitigate | Verify spawnSync with stdio:pipe pattern preserved (not execSync); error path calls process.exit(1) |
| T-07-05 | Information Disclosure | hooks/gsd-check-update-worker.js GitHub API call | accept | User-Agent header set; no auth token used; public API endpoint only |
| T-07-06 | Elevation of Privilege | git merge --allow-unrelated-histories | accept | Standard merge (no --allow-unrelated-histories flag); normal three-way merge semantics |
| T-07-07 | Repudiation | Merge commit message | mitigate | Commit message format per D-08 records upstream version, commit count, and conflict file count |
</threat_model>
