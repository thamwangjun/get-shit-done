# Phase 35 Plan 01: Backup and Soft Reset

## Objective

Establish dual-layer backup (git branch and physical directory) and soft reset HEAD to tag `v1.41.2` while keeping modifications unstaged. This is the safety-preservation step before refactoring the git commit history across Phases 36-41.

## Context

- **ROADMAP.md**: Phase 35 is the first phase of the v1.41.5 "Refactor Git Commit History" milestone. It is a prerequisite for all subsequent staging phases (36-40) and the final verification phase (41).
- **REQUIREMENTS.md**: Covers requirements GITOPS-01 (dual-layer backup) and GITOPS-02 (soft reset to v1.41.2).
- **STATE.md**: Current position at Phase 35; milestone v1.41.5 active.

## Tasks

### Task 35-01-01: Create backup branches (GITOPS-01)

Create local backup branches pointing to the current HEAD to preserve the full commit history before the soft reset.

- Create branch `backup-thamw-main-before-squash` at current HEAD.
- Create branch `backup-thamw-main-with-planning` at current HEAD (includes all `.planning/` state).
- Copy the entire working directory (including `.planning/`) to `../get-shit-done-backup/` for a physical backup.

### Task 35-01-02: Soft reset to v1.41.2 (GITOPS-02)

Reset HEAD while preserving working directory modifications unstaged.

- Run `git reset --soft v1.41.2` to move HEAD to the tag while keeping all file modifications as unstaged changes.
- Verify that `HEAD` points to tag `v1.41.2`.
- Verify that the working tree still contains all modified files.

## Success Criteria

- Local backup branch `backup-thamw-main-before-squash` created pointing to current HEAD.
- Local backup branch `backup-thamw-main-with-planning` created pointing to current HEAD.
- Full backup directory created outside the working directory at `../get-shit-done-backup/`.
- Git soft reset to `v1.41.2` runs successfully.
- Working tree contains all modified files unstaged, and HEAD is at tag `v1.41.2`.
