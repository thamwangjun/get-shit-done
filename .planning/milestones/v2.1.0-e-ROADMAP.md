# Milestone v2.1.0-e: Per-Agent Thinking Effort

**Status:** ✅ SHIPPED 2026-06-06
**Phases:** 52–58 (plus inserted 55.1, 55.2)
**Total Plans:** 28

## Overview

Added a unified, Claude-first thinking-effort dimension encoded inline as `model;effort` labels (semicolon delimiter). The effort is resolved through the existing model machinery and passed to `Agent()` spawns. The change is additive plumbing — bare configs resolve identically before D-08 for model values — but the effort *semantics* deliberately change: bare `{claude, codex}` slots now floor to `medium` instead of resolving to `null`/omit (Phase 56 D-08). `inherit` slots and the 8 non-effort runtimes still omit.
