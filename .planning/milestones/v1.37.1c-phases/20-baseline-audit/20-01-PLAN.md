Create `scripts/audit-tags.js` as a Node.js CJS script (no shebang needed, invoked
as `node scripts/audit-tags.js`). The script:

1. **Defines the level map** — hardcode the 5 scanning targets:

```js
const LEVELS = [
  { level: 1, label: 'Level 1 — Agents',      dir: path.join(ROOT, 'agents'),
    filter: f => f.startsWith('gsd-') && f.endsWith('.md'),
    canonical: 'persona' },
  { level: 2, label: 'Level 2 — Commands',     dir: path.join(ROOT, 'commands', 'gsd'),
    filter: f => f.endsWith('.md'),
    canonical: 'intent' },
  { level: 3, label: 'Level 3 — Workflows',    dir: path.join(ROOT, 'get-shit-done', 'workflows'),
    filter: f => f.endsWith('.md'),
    canonical: 'objective' },
  { level: 4, label: 'Level 4a — Templates',   dir: path.join(ROOT, 'get-shit-done', 'templates'),
    filter: f => f.endsWith('.md'),
    canonical: 'task' },
  { level: 5, label: 'Level 4b — References',  dir: path.join(ROOT, 'get-shit-done', 'references'),
    filter: f => f.endsWith('.md'),
    canonical: 'task' },
];
```

Where `ROOT = path.join(__dirname, '..')`.

2. **Defines the primary directive tag list** (tags to detect):
```js
const PRIMARY_TAGS = ['persona', 'intent', 'objective', 'task', 'role', 'purpose'];
```

3. **Implements `detectTags(content)`**:
   - Strip code fences: `content.replace(/```[\s\S]*?```/g, '')`
   - Strip inline backticks: `.replace(/`[^`]+`/g, '')`
   - Split on `\n` and scan each line
   - For each `tag` in `PRIMARY_TAGS`: if `line.trim() === '<' + tag + '>'`, record it
   - Return array of matched tag names (deduplicated, preserving order of first occurrence)

4. **Implements `classifyStatus(foundTags, canonical)`**:
   - `foundTags.length === 0` → `'missing'`
   - `foundTags.length > 1` → `'multiple'`
   - `foundTags[0] === canonical` → `'ok'`
   - else → `'wrong-level'`

5. **Scans all levels** — for each level:
   - `fs.readdirSync(dir).filter(filter).sort()`
   - For each file: read content, call `detectTags`, call `classifyStatus`
   - Build entry: `{ file: relativePath, found_tags: [...], expected_tag: canonical, status }`
   - Compute counts: `ok`, `anomalies` (= total - ok)

6. **Writes JSON output** to `.planning/phases/20-baseline-audit/20-BASELINE-AUDIT.json`:

```json
{
  "generated": "<new Date().toISOString()>",
  "levels": [ ...levelObjects ]
}
```

Where `relativePath` = path relative to repo root (e.g. `"agents/gsd-advisor-researcher.md"`).

7. **Writes Markdown output** to `.planning/phases/20-baseline-audit/20-BASELINE-AUDIT.md`:

Top of file:
```
# Tag Hierarchy Baseline Audit — v1.37.1c

Generated: <ISO timestamp>
In-scope corpus: upstream/v1.37.1 file set
```

For each level (5 sections):
```markdown
## Level N — <label>

**Canonical tag:** `<tag>`
**Files scanned:** N
**OK:** N | **Anomalies:** N (missing: N, wrong-level: N, multiple: N)

| File | Found Tag(s) | Expected | Status |
|------|-------------|----------|--------|
| agents/gsd-foo.md | persona | persona | ok |
| agents/gsd-bar.md | none | persona | missing |
```

Where "Found Tag(s)" shows comma-joined `found_tags`, or `"none"` if empty.

8. **Prints a console summary** on completion:

```
Audit complete. Files scanned: 274. Anomalies: N.
Written: .planning/phases/20-baseline-audit/20-BASELINE-AUDIT.json
Written: .planning/phases/20-baseline-audit/20-BASELINE-AUDIT.md
```
