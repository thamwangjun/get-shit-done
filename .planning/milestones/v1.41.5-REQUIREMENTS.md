## Out of Scope

| Feature | Reason |
|---------|--------|
| Squashing into a single commit | Loses all logical separation of config, scanners, prompts, tests, and logs in git history. |
| Interactive rebase (`git rebase -i`) | Over 800 divergent commits make interactive rebase extremely conflict-prone and inefficient. |
| Making code or prompt content fixes | Changing file contents during history refactoring violates the zero-diff parity gate and increases risk of introducing regression bugs. |
| Running tests on intermediate commits | Category-based batching splits prompt logic from its tests, causing intermediate commits to have failing test suites. |
