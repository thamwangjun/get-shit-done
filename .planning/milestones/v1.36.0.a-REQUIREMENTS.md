# Requirements: v1.36.0.a Fix Update Functionality

## Milestone Goal

Fix the /gsd-update command and background update-check hook so update detection works correctly with the fork's SHA-based versioning (replacing upstream's npm semver scheme).

## v1 Requirements

### Update Hook (Background Check)

- [x] **HOOK-01**: User sees "GSD is up to date" in the statusline when the installed SHA matches the remote fork's HEAD SHA
- [x] **HOOK-02**: User sees an update notification only when the fork's remote HEAD SHA (thamw-main) differs from the installed SHA
- [x] **HOOK-03**: The background update-check worker (`gsd-check-update-worker.js`) runs without crashing — no `ReferenceError` from the undefined `isNewer` function
- [x] **HOOK-04**: The worker fetches the latest version from the fork's GitHub repo (`thamwangjun/get-shit-done`, `thamw-main`), not the upstream npm registry (`get-shit-done-cc`)

### Version Detection (Installer)

- [x] **INST-01**: The VERSION file always contains a 7-char hex SHA after a successful installation
- [x] **INST-02**: When the GitHub API is unavailable at install time, the VERSION file is written with a value that version detection can distinguish from a valid SHA (prevents silent semver fallback that breaks SHA-based comparison)

### Update Workflow (/gsd-update)

- [~] **UPD-01**: The update workflow (`update.md`) correctly reports "already on latest" when the installed SHA equals the remote SHA — code path verified by static analysis; live end-to-end run not performed (AI workflow, not shell-scriptable)
- [x] **UPD-02**: The version comparison in the workflow executes in a single bash context so variable state is not lost between steps

## Future Requirements

- Support for multi-fork installs where the upstream npm package is also installed alongside the fork

## Out of Scope

- Changing to semver-based versioning — the fork intentionally uses SHA-based tracking
- Upstream npm package (`get-shit-done-cc`) update notifications — this fork does not publish to npm
- Windows-specific version detection paths
