**File header (module-level JSDoc):** Document the violation classes, SCAN_DIRS, PATTERN_C_EXCLUDES, and the Phase 48 RED expectation listing the 6 violating files with their specific violations.

**Module-scope file collection:** Copy the `collectMarkdownFiles` hoisted function declaration from the analog (ENOENT-tolerant recursive collector). Collect `ALL_FILES` via the `for...of SCAN_DIRS` loop. Then filter: `SCAN_FILES = ALL_FILES.filter(f => !PATTERN_C_EXCLUDES.has(path.relative(PROJECT_ROOT, f).split(path.sep).join('/')))` — the `.split(path.sep).join('/')` normalizes Windows separators.

**`scanContent(content)` function:**
- Implements Pattern A/B detection with `STEP_DECIMAL_RE = /(?:^|\s|\*\*)Step\s+\d+\.\d/i` (per D-05: no indentation guard; the `\d` at end excludes letter suffixes like `7a` — the regex matches a digit after the dot, not a letter)
- Implements Pattern D detection with `/^\s{0,2}\d+\.\d+\./` (columns 0-2 only, per RESEARCH.md Pitfall 5)
- Uses `inCodeBlock` toggle on `` ``` `` lines (per RESEARCH.md Pattern 3)
- Returns `{ patternAB: [...], patternD: [...] }` — each item is `{ lineNumber, line }` where `lineNumber` is 1-indexed and `line` is `trimmed`

**`scanForOutOfOrder(content)` function:**
- Tracks `expectedNext = null` (integer or null)
- Resets `expectedNext = null` on `##` or `###` heading lines (per D-04)
- Detects whole-integer steps with `/\*?\*?Step\s+(\d+)(?![\.\da-z])/i` — negative lookahead excludes decimal labels (the `.` chars), other digits, and letter suffixes (per RESEARCH.md Pattern 4)
- When `expectedNext === null`: sets `expectedNext = n + 1` (handles Step 0 as valid start per RESEARCH.md Pitfall 4)
- When `n !== expectedNext`: pushes `{ lineNumber: i+1, expected: expectedNext, actual: n, line: trimmed }` and sets `expectedNext = n + 1` (advances from actual, not expected, to limit cascading errors)
- Returns array of violation objects
- Uses `inCodeBlock` toggle (same as `scanContent`)

**`describe('scanContent() — decimal detection', ...)` block — 7 unit tests with synthetic string fixtures:**
1. Flags `**Step 2.5:** do thing` as Pattern A/B (assert `patternAB.length === 1`)
2. Flags `**Step 7.0 — branch label**` as Pattern A/B (per D-08 — Step N.0 IS a violation; assert `patternAB.length === 1`)
3. Flags `   **Step 7.0** indented sub-step` as Pattern A/B (per D-05 — no indentation guard; assert `patternAB.length === 1`)
4. Does NOT flag `**Step 7a:** branch label` (letter suffix; assert `patternAB.length === 0`)
5. Does NOT flag `**Step 7:** do thing` (whole integer; assert `patternAB.length === 0`)
6. Flags `5.5. **Worktree cleanup**` as Pattern D (assert `patternD.length === 1`)
7. Does NOT flag Pattern D inside code block: content `'```\n5.5. inside fence\n```\n'` (assert `patternD.length === 0`)

**`describe('scanForOutOfOrder() — synthetic content', ...)` block — 6 unit tests:**
1. Flags reversed sequence `## Section\n**Step 1:** a\n**Step 3:** b\n**Step 2:** c` — expect `violations.length === 2` (both Step 3 and Step 2 trigger)
2. Flags gap `## Section\n**Step 1:** a\n**Step 3:** b` — expect `violations.length === 1`
3. Does NOT flag valid sequence `## Section\n**Step 0:** a\n**Step 1:** b\n**Step 2:** c` (Step 0 valid start)
4. Does NOT flag reset on `## heading`: `## A\n**Step 1:** a\n## B\n**Step 1:** restart` — expect `violations.length === 0`
5. Does NOT flag reset on `### heading`: same pattern with `### Subsection`
6. Ignores steps inside code blocks: `## A\n**Step 5:** a\n\`\`\`\nStep 1 inside\nStep 2 inside\n\`\`\`\n**Step 6:** b` — expect `violations.length === 0`

**Three corpus `describe` blocks (per D-06 — per-file subtests, not aggregate):**

Block 1: `describe('corpus scan — decimal step labels (Pattern A/B)', ...)` — for each file in `SCAN_FILES`, emit a dynamic `test('no decimal Pattern A/B labels in ${relPath}', ...)` that reads the file, calls `scanContent(content)`, and asserts `deepStrictEqual(patternAB, [], ...)`.

Block 2: `describe('corpus scan — decimal ordered-list items (Pattern D)', ...)` — same shape but destructures `patternD`.

Per D-01, this block is expected to pass GREEN (or partially pass) — corpus may have no genuine out-of-order violations.

In all three blocks, `relPath = path.relative(PROJECT_ROOT, file).split(path.sep).join('/')`.
