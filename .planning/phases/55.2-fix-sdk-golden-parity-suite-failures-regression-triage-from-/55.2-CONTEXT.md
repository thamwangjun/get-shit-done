<decisions>
## Implementation Decisions

### D-201: Inherit 55.1 policy — root-cause each, never relax assertions
Carry forward 55.1's D-101/D-104/D-105: each failure is independently root-caused
(missing-handler / stale-fixture / real-divergence); assertions are NEVER relaxed to
hide divergence; golden fixtures are regenerated ONLY from confirmed-correct output;
the whole suite ends green with no new skips.

### D-202: Bisect rigor — best-effort, suspect-first (not exhaustive bisect)
Confirm the regression (SDK suite green before phase 55, failing at the phase-55
completion commit `30108028`), then root-cause from the named suspects `e4a841cd`
and `abfcbf2b` (phase 55-01), with phase-54 SDK work (`44c150b42`, `f0107ba64`,
`26679eb8c`) as secondary candidates. Record the strongest evidence in VERIFICATION.
Only fall back to full multi-checkout bisection if the named suspects do not explain
the failures. Rationale: repeated full SDK-suite runs at many checkouts are costly;
the introducing surface is already narrowed.

### D-203: Parity oracle default — gsd-tools.cjs is canonical
On any CLI-vs-SDK drift, `gsd-tools.cjs` is the reference oracle by design: fix the
SDK handler to match it. Override this default ONLY with concrete evidence that the
CLI itself regressed during phase 55 (in which case fix the CLI and note it). Stale
golden fixtures are regenerated from confirmed-correct CLI output (per D-201/D-104).

### D-204: Missing handlers — implement by default, exception as documented fallback
Default: register native handlers for `intel.update` and `verify.codebase-drift`,
mirroring existing analogs (`intel.status` / `verify.schema-drift`) so they dispatch
and satisfy the `native_failure` classification + golden coverage policy. If
investigation proves one is intentionally CLI-only (no native parity intended), adding
it to the golden-integration coverage-exception allowlist
(`sdk/src/golden/golden-integration-covered.ts`) is acceptable — but only with an
explicit rationale recorded in VERIFICATION. Exception is the fallback, not the path.

### D-205: VERIFICATION must classify all 17 + name the introducing commit
55.2-VERIFICATION.md records, per failing test, whether the cause was
missing-handler / stale-fixture / real-divergence, plus the introducing commit (or
narrowed surface) found during investigation.

  Capture constraints (bisect-first gating, cluster grouping, final whole-suite gate
  mirroring 55.1-04) as guidance, but the planner owns the actual plan/wave breakdown.
