find agents/ get-shit-done/workflows/ -type f -name '*.md' -print0 | \
  xargs -0 sed -i '' -E '/# omit this line when/!s/^([[:space:]]+)(effort=\{([A-Za-z_][A-Za-z_0-9]*_effort_arg)\})[[:space:]]*$/\1\2  # omit this line when \3 == null/'

Notes for executor:
- Use `[[:space:]]` POSIX class rather than `\s` for BSD sed portability.
- The `/# omit this line when/!` address is the idempotency guard (D-02) — lines already carrying the comment are skipped.
- Replacement injects two spaces before `#` per CONTEXT.md Claude's Discretion.
- Do not modify inline `effort={...}` occurrences; the `^...$` anchors guarantee standalone-only (D-03).

Step 3 — Idempotency check (per D-02): re-run the same sed command; `git diff --stat` must show zero changes from this second run.

# Snapshot diff stat after first sed run

find agents/ get-shit-done/workflows/ -type f -name '*.md' -print0 | \

diff /tmp/0kd-after-first.txt /tmp/0kd-after-second.txt || { echo "ABORT: sed is not idempotent"; exit 1; }
