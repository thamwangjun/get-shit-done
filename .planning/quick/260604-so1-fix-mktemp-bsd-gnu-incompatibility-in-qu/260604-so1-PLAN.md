<objective>
Fix a BSD/GNU `mktemp` incompatibility in the quick workflow's worktree manifest path template.

Purpose: BSD `mktemp` (macOS) only substitutes a trailing run of `X`s. Because `.json` currently follows the `XXXXXX`, BSD leaves `XXXXXX` literal and creates a fixed path `gsd-quick-worktree-XXXXXX.json`, causing every run on macOS to collide on one path and silently reuse stale manifests. GNU mktemp substitutes correctly, so the bug is macOS-only.

Output: A single edited line in `get-shit-done/workflows/quick.md` that keeps the `X`s trailing and concatenates `.json` after `mktemp` returns — portable across both implementations with otherwise unchanged behavior.
</objective>
