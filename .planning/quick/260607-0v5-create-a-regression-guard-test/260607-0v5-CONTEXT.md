# Quick Task 260607-0v5: bare-effort-arg regression guard test - Context

**Gathered:** 2026-06-07
**Status:** Ready for planning

<domain>
## Task Boundary

Create `tests/bare-effort-arg-scan.test.cjs` — a regression guard that fails if any
`{*_effort_arg}` token appears in an Agent() invocation without the required `effort=`
prefix. Prevents regressions to the bug fixed in quick task 260606-x8b.

</domain>

<decisions>
## Implementation Decisions

### Exclusion mechanism
Use a **paren-depth state machine** to identify Agent() invocation regions, not backtick
stripping. When `Agent(` is encountered, start tracking depth; depth > 0 means we're
inside an Agent() call. Only check tokens found within those regions.

Rationale: the original spec proposed backtick stripping, but the actual rule is
"violations are tokens inside Agent() invocations". Prose lines (execute-phase.md:87 and
map-codebase.md:157) are excluded because paren depth is 0 there — no allowlist or
stripping needed.

### Code fence / backtick spans
Strip nothing. Agent() invocation examples inside fenced code blocks ARE real invocations
and should be checked. Backtick spans that happen to contain `{*_effort_arg}` inside an
Agent() call should also be checked.

### Scan scope
All prompt file directories: `agents/`, `get-shit-done/workflows/`, AND `commands/gsd/`.
`commands/gsd/` currently has no effort_arg tokens but should be included as a natural
regression target.

### Violation detection
Within Agent() regions, find `{*_effort_arg}` tokens where the 7 characters immediately
before `{` are NOT `effort=`. Record as `{ file, line, col, token }`.

### Test must pass today
Verified with a prototype scan: all three directories are currently clean.

</decisions>

**State machine (verified working):**
- Process each line char by char
- When `Agent(` is detected, set depth=1
- Subsequent `(` increments depth, `)` decrements
- When depth returns to 0, we've left the Agent() call
- Check each line where depth > 0 (or depth was > 0 when line started) for bare tokens
