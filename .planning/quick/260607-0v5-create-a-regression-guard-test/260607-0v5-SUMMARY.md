# Phase quick-260607-0v5 Plan 01: Bare Effort Arg Regression Guard Summary

Regression guard using paren-depth state machine to detect bare {*_effort_arg} tokens inside Agent() invocations — prevents recurrence of the 260606-x8b bug.

## What Was Built

`tests/bare-effort-arg-scan.test.cjs` — a Node.js built-in `--test` runner test that:

1. Collects all `.md` files from `agents/`, `get-shit-done/workflows/`, and `commands/gsd/`
2. For each file, runs a paren-depth state machine that tracks whether each character position is inside an `Agent(...)` call
3. Within Agent() regions, identifies `{*_effort_arg}` tokens
4. For each token, checks whether the 7 characters before `{` are `effort=`
5. Fails with a detailed violation list if any bare token is found
