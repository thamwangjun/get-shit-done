# Quick Plan 260530-7yv: implement the 1-line os.availableParallelism() fix in run-tests.cjs

## Context

Spike 001 (`.planning/spikes/001-node-test-concurrency/README.md`) confirmed the hardcoded default of `4` in `run-tests.cjs` is conservative for the 32-CPU machine. The fix: replace `4` with `os.availableParallelism()` so the test suite automatically uses all available cores without requiring `TEST_CONCURRENCY` override.

## Tasks

### Task 1: Add os import and replace hardcoded concurrency default

**files:** `scripts/run-tests.cjs`
**action:** Add `const os = require('os');` to imports. Change `const defaultConcurrency = process.platform === 'win32' ? 2 : 4;` to `const defaultConcurrency = process.platform === 'win32' ? 2 : os.availableParallelism();`
**verify:** `node -e "const os = require('os'); console.log(os.availableParallelism());"` returns a number; script still loads without error
**done:** Line 142 uses `os.availableParallelism()` instead of `4`
