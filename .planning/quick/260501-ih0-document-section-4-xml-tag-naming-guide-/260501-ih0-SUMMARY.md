# Summary: Section 4 XML tag naming guide rewrite

## What was done

Rewrote Section 4's XML tag section in `PROMPT_ENGINEERING_GUIDE_V09.md` from a glossary (~150 tags in tables) into a naming guide organized by 14 tag categories. Each category now has prose guidance on naming principles and when to use that class of tag — no vocabulary tables.
